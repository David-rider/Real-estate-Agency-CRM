# Real Estate Agency CRM

An open-source CRM built for real estate brokerages to manage clients,
listings, and commissions — built for, and in production use at, a real
estate brokerage in New York.

## What it does

- **Client management** — keep track of buyers, sellers, and their contact
  details in one place.
- **Listing management** — manage property listings through the sales pipeline.
- **Commission tracking** — track commissions on closed deals.
- **Excel import/export** — move data in and out with spreadsheets.

## Live demo

https://real-estate-agency-crm.vercel.app

- TypeScript
